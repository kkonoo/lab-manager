# 랩 매니저

연구실을 한곳에서 꾸리는 웹앱(PWA)이에요. 제목 옆 **[행정 | 연구]** 스위치로 모드를 바꿔요. **연구 모드**(프로토콜·계산기·재고·기기·팁)는 학생과 같이 쓰고, **행정 모드**(한눈에 보기·예산·인건비·서류·정보)는 PI만 봐요. 마지막에 쓴 모드로 다시 열려요. 설치 없이 브라우저에서 열고, 폰에서는 홈 화면에 추가해 앱처럼 써요.

**주소: https://kkonoo.github.io/lab-manager/**

## 처음 쓸 때

1. 처음엔 **예시 데이터**(가짜 과제·학생·금액·프로토콜)가 들어 있어요. 둘러보고 고쳐 쓰거나 지우고 시작해요.
2. **서류 탭 → 👤 내 정보**에 소속·성명·연락처·도장·서명(영문 레터용 영문 이름·직함·주소도)을 넣으면 서류마다 미리 채워져요.
3. 오른쪽 위 **로그인**(구글 계정)을 하면 PC·폰에서 같은 데이터를 봐요. 로그인 전에는 이 브라우저에만 저장돼요.
4. 이미 쓰던 데이터가 있으면 **설정 → 데이터 → 가져오기**로 JSON 파일을 넣어요 (내보내기로 백업).

## 학생과 같이 쓰기

- **설정 → 계정 → 랩 멤버**에 학생의 구글 이메일을 적어요.
- 학생이 같은 주소에서 그 계정으로 로그인하면 **연구 모드**(프로토콜·계산기·재고·기기·팁)만 보여요. 프로토콜·품목·살 것·보관 위치·주문·받음·기기 페이지를 같이 쓰고, 주문의 재원(과제·세목)·기기 사진·팁 링크는 PI만 정해요.
- 행정 모드(예산·인건비·서류·정보)는 학생에게 보이지 않아요. Firestore 보안 규칙이 서버에서 막아요.

## 실험 계산기

연구 모드의 **계산기** 탭이에요 (PI·랩 학생 모두, 로그인 안 해도 계산은 돼요). 계산 값은 저장하지 않아요. 왼쪽 목록(폰에선 위 2×2)에서 고른 계산기 하나가 보이고, 칸을 채우면 바로 계산돼요 (다른 계산기나 탭에 갔다 와도 넣은 값은 그대로): **몰농도**(질량 = 몰농도 × 부피 × MW, 셋 중 빈 칸을 계산), **희석**(C1V1 = C2V2, 몰농도·mg/mL·배수 X를 자동 변환해 'stock 10 µL + 용매 990 µL'처럼), **버퍼 조제**(최종 부피와 성분 행 → 성분별 g·mL 표, 프리셋을 불러와 고치기, pH는 직접), **세포 seeding**(hemocytometer 평균 × 희석배수 × 10⁴ = cells/mL 또는 직접 입력 → 6~96-well 프리셋의 웰 면적·권장 부피로 '현탁액 ○ mL + 배지 ○ mL', 여유분 % 포함). 부피는 2 mL 아래면 µL로 보여 주고(세포 카드는 mL), 0·음수·빈칸은 결과 칸에 짧은 안내만 떠요. 예전 주소(`calc.html`)로 열면 이 탭으로 넘어와요.

**버퍼 프리셋 공유** — 로그인하면 PI와 랩 학생이 같은 프리셋을 봐요 (로그인 전엔 기본 프리셋 PBS 1X·TBS 1X·10X TAE만). PI만 프리셋 줄 끝의 **+**로 지금 표를 프리셋으로 저장하고, 프리셋을 **길게 눌러**(PC는 오른쪽 클릭) 이름·pH 메모 바꾸기, 지금 표로 바꾸기, 지우기를 해요. 기본 프리셋도 고치거나 지울 수 있고 + 창의 **기본 프리셋 되돌리기**로 처음 값으로 돌아와요 (직접 만든 건 그대로). 랩 학생은 보기만 하고, PI가 고치면 학생 화면에도 바로 바뀌어요.

## 기기 사진

기기 탭에서 PI가 **+ 사진**으로 넣어 두면 랩 학생은 보기만 해요 (누르면 크게). 따로 설정할 것 없이 사진을 **긴 변 1600px JPEG로 줄여서 앱 안**(Firestore `labs/{PI uid}/photos`)에 저장해요 — 다른 교수님 랩도 그대로 써요.

### (선택) 원본을 내 Google Drive에

**설정 → 기기 사진 저장 → Google Drive 연결**을 누르고 구글 계정을 고른 뒤 허용하면 끝이에요 (교수님마다 각자 자기 Drive). 내 Drive에 **‘랩 매니저 기기 사진’** 폴더가 생기고, 그 뒤 넣는 사진 원본이 거기로 가요. 앞서 넣은 사진은 앱 안에 그대로 있어요.

- 앱이 받는 권한은 `drive.file` 하나예요 — **앱이 만든 파일만** 보고 고칠 수 있고, Drive의 다른 파일은 못 봐요.
- 사진은 '링크가 있는 모든 사용자: 보기'로 올려요 (학생 폰에서 띄우려고). 학교(Workspace) 계정은 관리자가 이 공유를 막아 둔 경우가 있어서, 사진이 '못 불러왔어요'로 나오면 개인 Gmail 계정으로 다시 연결해요.
- 구글 권한은 1시간마다 풀려요. 그 뒤 처음 사진을 넣거나 지울 때 구글 창이 잠깐 떴다 닫혀요 (넣을 때는 **+ 사진**을 한 번 더 눌러 골라요).
- 앱에서 사진을 지우면 Drive 휴지통으로 가요 (30일 안에는 되살릴 수 있어요).
- **연결 끊기**를 하면 앞으로 넣는 사진은 앱 안에 저장되고, 이미 올린 Drive 사진은 그대로 보여요.
- 구글 창은 Google Cloud 콘솔(프로젝트 `lab-manager-knumed`) › Google 인증 플랫폼 › 클라이언트의 **웹 클라이언트**(승인된 JavaScript 원본 `https://kkonoo.github.io`)로 떠요. 클라이언트 ID는 `js/equip.js`의 `DRIVE_CLIENT_ID`예요 (공개돼도 괜찮아요). 앱 주소를 바꾸면 원본에도 더해야 해요.

## 팁

- 앱에 들어 있는 팁은 저장소의 [`tips/`](tips) 폴더 md 파일이에요. 앱이 소제목·목록·체크리스트·표를 보기 좋게 그리고(폰에선 칸이 셋 이상인 표를 줄마다 카드로), **🖨 인쇄 / PDF**로 A4에 맞춰 인쇄해요. 모든 랩에 똑같이 보여요.
- 고치려면 md 파일을 고쳐 main에 올리면 바로 반영돼요. 새 팁은 `tips/`에 md 파일을 넣고 `js/tips.js`의 `TIP_FILES`와 `sw.js`의 `SHELL`에 한 줄씩 더해요.
- md에서 쓸 수 있는 것: `##`·`###` 소제목, `-` 목록, `1.` 순서, `- [ ]` 체크(종이에 펜으로 체크하는 네모), `>` 메모, `|` 표, `**굵게**`, `` `코드` ``. 맨 위 `#` 제목은 앱에선 패널 제목으로 대신해요.

### Google 문서 링크 넣기 (PI)

1. Google 문서에서 **공유 → 일반 액세스: 링크가 있는 모든 사용자 (뷰어)** 로 바꾸고 **링크 복사**.
2. 랩 매니저 **연구 → 팁 → + 팁 문서**에 이름·아이콘과 그 링크를 넣어요. 웹에 게시한 링크, Google 슬라이드·시트, Drive의 PDF 링크도 돼요. 이 랩에만 보이고, 앱에 들어 있는 팁 아래에 붙어요.
3. 내용은 Google 문서에서 고치면 앱에도 그대로 보여요. 인쇄·PDF는 **Google 문서에서 열기 → 파일 → 인쇄**.

## 데이터는 어디에

- 로그인하면 구글 Firebase(Firestore)에 저장돼요. PI 데이터는 `users/{내 uid}`, 연구 모드 데이터(프로토콜·재고·기기·팁 목록)는 `labs/{내 uid}`에 있고, `firestore.rules`가 본인(연구 쪽은 랩 멤버까지)만 읽고 쓰게 막아요.
- 기기 사진은 앱 안 저장이면 `labs/{PI uid}/photos/{id}`에 사진 하나 = 문서 하나(줄인 JPEG)로 있고, 기기 페이지엔 사진 id만 있어요. Google Drive를 연결했으면 원본은 PI의 Drive ‘랩 매니저 기기 사진’ 폴더에, 기기 페이지엔 Drive 파일 id만 있어요.
- 계산기의 버퍼 프리셋만 `calcPresets/{내 uid}`에 따로 있어요. **누구나 읽기(문서 하나씩, 목록 훑기는 안 됨)**, 고치기는 본인만이에요. `firestore.rules`를 바꿨으면 Firebase 콘솔 > Firestore Database > 규칙에 다시 붙여 넣고 게시해요.
- 금액은 모두 **천원** 단위로 저장해요 (인건비 화면만 만원으로 보여요).
- 기준 인건비·중앙구매 기준은 설정에서 **시행 월**과 함께 바꿔요. 지난 달 참여율과 지난 주문은 그때 기준대로 계산돼요.

## 개발

빌드 없음 — 정적 HTML/CSS/JS 그대로예요.

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File tools/serve.ps1
```

http://localhost:8768 에서 열려요. 아이콘은 `tools/make-icons.ps1`, HWP 양식 구조 보기는 `tools/hwpdump.ps1`.
