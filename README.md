# 랩 행정

연구실 행정을 한곳에서 보는 웹앱(PWA)이에요. 설치 없이 브라우저에서 열고, 폰에서는 홈 화면에 추가해 앱처럼 써요.

**주소: https://kkonoo.github.io/lab-admin/**

| 탭 | 하는 일 |
|---|---|
| 한눈에 | 확인할 것(기간 밖 인건비·배정액 빈 칸·오래 기다리는 주문 등), 과제 기간·연차, 이번 달 학생별 인건비 |
| 재원별 예산 | 과제(책임·참여)·BK21별 연차 예산, 세목 예산(계획·집행), 과제 개요 |
| 인건비 | 학생 × 재원 × 월 인건비 표 (학기 보기 / 월 보기), 참여율, 가상 학생 시뮬레이션 |
| 재고 | 장보기처럼 '살 것' → 주문 → 받음, 보관 위치 지도, 프로토콜·실험별 재료, 업체 연락처. 주문 금액은 세목 집행에 더해짐 |
| 서류 | 학교 양식(교육 중간보고서·출장 서류·구매 규격서·회의록·영문 레터)을 채워 A4 PDF로 저장 |
| 정보 | 행정 절차 노트, 행정 정보 표(🔒 칸은 가려서 보임), 내선번호 |

## 처음 쓸 때

1. 처음엔 **예시 데이터**(가짜 과제·학생·금액)가 들어 있어요. 둘러보고 고쳐 쓰거나 지우고 시작해요.
2. **서류 탭 → 👤 내 정보**에 소속·성명·연락처·도장·서명을 넣으면 서류마다 미리 채워져요.
3. 오른쪽 위 **로그인**(구글 계정)을 하면 PC·폰에서 같은 데이터를 봐요. 로그인 전에는 이 브라우저에만 저장돼요.
4. 이미 쓰던 데이터가 있으면 **설정 → 데이터 → 가져오기**로 JSON 파일을 넣어요 (내보내기로 백업).

## 학생과 재고 같이 쓰기

- **설정 → 계정 → 랩 멤버**에 학생의 구글 이메일을 적어요.
- 학생이 같은 주소에서 그 계정으로 로그인하면 **재고 탭만** 보여요. 품목·살 것·보관 위치·주문·받음을 같이 쓰고, 주문의 재원(과제·세목)은 PI만 정해요.
- 과제·인건비·정보·서류는 학생에게 보이지 않아요. Firestore 보안 규칙이 서버에서 막아요.

## 데이터는 어디에

- 로그인하면 구글 Firebase(Firestore)에 저장돼요. 내 데이터는 `users/{내 uid}`, 재고는 `labs/{내 uid}`에 있고, `firestore.rules`가 본인(재고는 랩 멤버까지)만 읽고 쓰게 막아요.
- 금액은 모두 **천원** 단위로 저장해요 (인건비 화면만 만원으로 보여요).
- 기준 인건비·중앙구매 기준은 설정에서 **시행 월**과 함께 바꿔요. 지난 달 참여율과 지난 주문은 그때 기준대로 계산돼요.

## 만든 사람이 할 일 (Firebase 설정)

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만들고 **웹 앱**을 추가해요. 나온 `firebaseConfig`를 `firebase-config.js`에 붙여 넣어요.
2. **Authentication → 로그인 방법 → Google** 사용, **설정 → 승인된 도메인**에 `kkonoo.github.io` 추가 (localhost는 기본으로 있음).
3. **Firestore Database**를 만들고(위치 `asia-northeast3` 서울), **규칙**에 `firestore.rules` 내용을 붙여 넣고 게시해요.

## 개발

빌드 없음 — 정적 HTML/CSS/JS 그대로예요.

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File tools/serve.ps1
```

http://localhost:8768 에서 열려요. 아이콘은 `tools/make-icons.ps1`, HWP 양식 구조 보기는 `tools/hwpdump.ps1`.

| 파일 | 내용 |
|---|---|
| `app.js` | 화면 전부 (탭별 render 함수), 저장(localStorage) |
| `sync.js` | 구글 로그인 + Firestore 동기화 (부분별 문서, 재고는 한 건씩) |
| `data.js` | 처음 예시 데이터 |
| `forms*.js` | 서류 양식 (HTML 표로 옮긴 학교 양식) |
| `firestore.rules` | 보안 규칙 (콘솔에 붙여 넣는 원본) |
