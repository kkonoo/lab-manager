# 랩 매니저

연구실을 한곳에서 꾸리는 웹앱(PWA)이에요. 제목 옆 **[행정 | 연구]** 스위치로 모드를 바꿔요. **연구 모드**(프로토콜·재고·기기·팁)는 학생과 같이 쓰고, **행정 모드**(한눈에 보기·예산·인건비·서류·정보)는 PI만 봐요. 마지막에 쓴 모드로 다시 열려요. 설치 없이 브라우저에서 열고, 폰에서는 홈 화면에 추가해 앱처럼 써요.

**주소: https://kkonoo.github.io/lab-manager/**

## 처음 쓸 때

1. 처음엔 **예시 데이터**(가짜 과제·학생·금액·프로토콜)가 들어 있어요. 둘러보고 고쳐 쓰거나 지우고 시작해요.
2. **서류 탭 → 👤 내 정보**에 소속·성명·연락처·도장·서명(영문 레터용 영문 이름·직함·주소도)을 넣으면 서류마다 미리 채워져요.
3. 오른쪽 위 **로그인**(구글 계정)을 하면 PC·폰에서 같은 데이터를 봐요. 로그인 전에는 이 브라우저에만 저장돼요.
4. 이미 쓰던 데이터가 있으면 **설정 → 데이터 → 가져오기**로 JSON 파일을 넣어요 (내보내기로 백업).

## 학생과 같이 쓰기

- **설정 → 계정 → 랩 멤버**에 학생의 구글 이메일을 적어요.
- 학생이 같은 주소에서 그 계정으로 로그인하면 **연구 모드**(프로토콜·재고·기기·팁)만 보여요. 프로토콜·품목·살 것·보관 위치·주문·받음·기기 페이지·기기 사진을 같이 쓰고, 주문의 재원(과제·세목)과 팁 목록은 PI만 정해요.
- 행정 모드(예산·인건비·서류·정보)는 학생에게 보이지 않아요. Firestore 보안 규칙이 서버에서 막아요.

## 실험 계산기

**주소: https://kkonoo.github.io/lab-manager/calc.html** — 랩 매니저 위 오른쪽 🧮 버튼으로 새 창에서 여는 따로 페이지예요 (PI·랩 학생 모두). 랩 매니저의 데이터는 읽지 않고 계산 값도 저장하지 않아요. 왼쪽 목록(폰에선 위 2×2)에서 고른 계산기 하나가 보이고, 칸을 채우면 바로 계산돼요 (다른 계산기에 갔다 와도 넣은 값은 그대로): **몰농도**(질량 = 몰농도 × 부피 × MW, 셋 중 빈 칸을 계산), **희석**(C1V1 = C2V2, 몰농도·mg/mL·배수 X를 자동 변환해 'stock 10 µL + 용매 990 µL'처럼), **버퍼 조제**(최종 부피와 성분 행 → 성분별 g·mL 표, 프리셋을 불러와 고치기, pH는 직접), **세포 seeding**(hemocytometer 평균 × 희석배수 × 10⁴ = cells/mL 또는 직접 입력 → 6~96-well 프리셋의 웰 면적·권장 부피로 '현탁액 ○ mL + 배지 ○ mL', 여유분 % 포함). 부피는 2 mL 아래면 µL로 보여 주고(세포 카드는 mL), 0·음수·빈칸은 결과 칸에 짧은 안내만 떠요.

**버퍼 프리셋 공유** — 🧮가 주소에 이 랩(`?lab=PI uid`)을 붙여 열어서 PI와 랩 학생이 같은 프리셋을 봐요 (`?lab=` 없는 주소로 열면 기본 프리셋 PBS 1X·TBS 1X·10X TAE만). PI만 프리셋 줄 끝의 **+**로 지금 표를 프리셋으로 저장하고, 프리셋을 **길게 눌러**(PC는 오른쪽 클릭) 이름·pH 메모 바꾸기, 지금 표로 바꾸기, 지우기를 해요. 기본 프리셋도 고치거나 지울 수 있고 + 창의 **기본 프리셋 되돌리기**로 처음 값으로 돌아와요 (직접 만든 건 그대로). 랩 학생은 보기만 하고, 계산기엔 로그인 버튼이 없어요 (랩 매니저와 로그인을 같이 씀). 프리셋은 계산기를 열 때 한 번 받아 오니, 열어 둔 사이에 고쳤으면 새로고침하면 돼요.

## 기기 사진 저장 (Google Drive — 한 번만 설정)

기기 탭에서 사진을 올리면 원본이 **PI의 Google Drive**('랩 매니저 기기 사진' 폴더)에 저장돼요. 그러려면 PI가 Apps Script 웹 앱을 한 번 만들어야 해요 (10분 정도). 만들기 전에는 사진 칸만 꺼져 있고 나머지는 그대로 써요.

1. 사진을 둘 구글 계정으로 https://script.google.com 에 들어가 **새 프로젝트**를 만들어요.
2. `Code.gs` 내용을 모두 지우고, [`tools/photo-upload.gs`](tools/photo-upload.gs) 내용을 통째로 붙여 넣은 뒤 저장해요.
3. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱** → **실행 계정: 나**, **액세스 권한: 모든 사용자** → **배포**.
4. 권한 승인 창에서 계정을 고르고, '확인되지 않은 앱' 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동 → 허용**을 눌러요 (내 Drive에 사진 저장, Firestore로 로그인 확인).
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해서, 랩 매니저 **설정 → 기기 사진 저장 (Google Drive)**에 붙여 넣고 확인 → '기기 사진 저장이 연결됐어요.'가 뜨면 끝이에요.

- 웹 앱 주소는 누구나 부를 수 있지만, 앱이 보내는 로그인 토큰으로 이 랩의 PI·랩 멤버인지 확인하고(Firestore 규칙 그대로), 자기 폴더 밖의 파일은 지우지 않아요.
- 사진은 '링크가 있는 모든 사용자: 보기'로 저장돼요 (앱에서 띄우려고). 학교(Workspace) 계정은 관리자가 이 공유를 막아 둔 경우가 있어서, 사진이 '못 불러왔어요'로 나오면 개인 Gmail 계정으로 다시 만들어요.
- 앱에서 사진을 지우면 Drive 휴지통으로 가요 (30일 안에는 되살릴 수 있어요).
- `photo-upload.gs`가 바뀌면: **배포 → 배포 관리 → ✎ → 버전: 새 버전 → 배포** (주소는 그대로).

## 팁 문서 넣기

1. Google 문서에서 **공유 → 일반 액세스: 링크가 있는 모든 사용자 (뷰어)** 로 바꾸고 **링크 복사**.
2. 랩 매니저 **연구 → 팁 → + 팁 문서**에 이름·아이콘과 그 링크를 넣어요. 웹에 게시한 링크, Google 슬라이드·시트, Drive의 PDF 링크도 돼요.
3. 내용은 Google 문서에서 고치면 앱에도 그대로 보여요. 인쇄·PDF는 **Google 문서에서 열기 → 파일 → 인쇄**.

## 데이터는 어디에

- 로그인하면 구글 Firebase(Firestore)에 저장돼요. PI 데이터는 `users/{내 uid}`, 연구 모드 데이터(프로토콜·재고·기기·팁 목록)는 `labs/{내 uid}`에 있고, `firestore.rules`가 본인(연구 쪽은 랩 멤버까지)만 읽고 쓰게 막아요.
- 기기 사진 원본은 Firestore가 아니라 PI의 Google Drive에 있고, 기기 페이지엔 Drive 파일 id만 저장돼요.
- 실험 계산기의 버퍼 프리셋만 `calcPresets/{내 uid}`에 따로 있어요. **누구나 읽기(문서 하나씩, 목록 훑기는 안 됨)**, 고치기는 본인만이에요. `firestore.rules`를 바꿨으면 Firebase 콘솔 > Firestore Database > 규칙에 다시 붙여 넣고 게시해요.
- 금액은 모두 **천원** 단위로 저장해요 (인건비 화면만 만원으로 보여요).
- 기준 인건비·중앙구매 기준은 설정에서 **시행 월**과 함께 바꿔요. 지난 달 참여율과 지난 주문은 그때 기준대로 계산돼요.

## 개발

빌드 없음 — 정적 HTML/CSS/JS 그대로예요.

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File tools/serve.ps1
```

http://localhost:8768 에서 열려요. 아이콘은 `tools/make-icons.ps1`, HWP 양식 구조 보기는 `tools/hwpdump.ps1`.

| 파일 | 내용 |
|---|---|
| `js/app.js` | 공통: 상태·저장(localStorage)·탭 전환(render)·입력 창·설정·테마. 탭 파일보다 먼저 읽음 |
| `js/home.js` `budget.js` `pay.js` `docs.js` `info.js` `protocol.js` `stock.js` `equip.js` `tips.js` | 탭별 화면 (한눈에 보기·재원별 예산·인건비·서류(출장·내 정보 포함)·정보·프로토콜·재고·기기·팁) |
| `js/pages.js` | 프로토콜·기기가 같이 쓰는 틀 (묶음 → 페이지, 본문 노트, 인쇄) |
| `js/sync.js` | 구글 로그인 + Firestore 동기화 (PI 데이터는 부분별 문서, 프로토콜·기기·품목·주문은 한 건씩) |
| `js/data.js` | 처음 예시 데이터 |
| `js/forms*.js` | 서류 양식 (HTML 표로 옮긴 학교 양식) |

| `js/calc-sync.js` | 계산기 버퍼 프리셋 공유 (`?lab=` 링크일 때만 Firebase를 불러옴, Firestore lite) |
| `css/style.css` | 화면·인쇄 스타일 |
| `firestore.rules` | 보안 규칙 (콘솔에 붙여 넣는 원본) |
| `tools/photo-upload.gs` | 기기 사진을 PI의 Google Drive에 저장하는 Apps Script (PI가 웹 앱으로 배포) |
