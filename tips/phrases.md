# 논문 표현 (영어)

> 자주 쓰는 표현을 부분별로 모았어요. 그대로 붙이지 말고 내용에 맞게 바꿔 써요.

## 1. Introduction

| 하고 싶은 말 | 표현 |
|---|---|
| 중요성 | X is a leading cause of … / X plays a central role in … |
| 쌓인 근거 | Accumulating evidence indicates that … / Recent studies have shown that … |
| 아직 모름 (gap) | However, little is known about … / … remains unclear (poorly understood). / The mechanism by which X … has not been elucidated. |
| 목적 | In this study, we aimed to determine whether … / We hypothesized that … |
| 이 연구 요약 | Here, we show (demonstrate) that … / Our findings reveal … |

## 2. Methods (과거형 · 수동태가 기본)

- Cells were treated with X (10 µM) for 24 h.
- Mice were randomly assigned to … groups (n = 8 per group).
- … was performed as previously described [ref], with minor modifications.
- Data are presented as mean ± SD of three independent experiments.
- Statistical significance was determined by two-tailed unpaired t-test (or one-way ANOVA followed by Tukey's post hoc test). P < 0.05 was considered significant.

## 3. Results

| 하고 싶은 말 | 표현 |
|---|---|
| 늘었다 | increased · elevated · up-regulated · enhanced (… by 2.3-fold) |
| 줄었다 | decreased · reduced · down-regulated · attenuated (… by 40%) |
| 차이 없음 | did not differ significantly between … / was comparable between … |
| 용량·시간 의존 | in a dose-dependent (time-dependent) manner |
| 필요·충분 | X was required (sufficient) for … |
| 그림 가리키기 | (Fig. 2A) · as shown in Fig. 2A |
| 다음 질문으로 | To determine whether …, we next examined … |

- 결과에는 해석을 짧게: "…, suggesting that X regulates Y."
- 통계로 확인하지 않은 차이에 **significantly**를 쓰지 않아요.

## 4. Discussion

| 하고 싶은 말 | 표현 |
|---|---|
| 주요 발견 | In this study, we found that … |
| 기존과 같음 | Consistent with previous reports, … / These results are in line with … |
| 기존과 다름 | In contrast to …, we observed … / This discrepancy may be explained by … |
| 조심스러운 해석 | These findings suggest (indicate) that … / X may (might) … / It is likely that … |
| 의미 | These results raise the possibility that … / Our findings provide a rationale for … |
| 한계 | This study has several limitations. First, … Second, … |
| 앞으로 | Further studies are needed to … |
| 결론 | In summary (Taken together), our findings identify X as … |

- **prove**는 피하고 show · indicate · support를 써요.
- novel · first 주장은 정말 확인한 경우에만.

## 5. 이어 주는 말

| 뜻 | 표현 |
|---|---|
| 더하기 | In addition, · Furthermore, · Moreover, |
| 반대 | However, · In contrast, · Conversely, |
| 결과 | Therefore, · Thus, · Consequently, |
| 강조 | Notably, · Importantly, · Interestingly, (과용 X) |
| 요약 | Taken together, · Collectively, |

## 6. 헷갈리는 말

| 헷갈림 | 바르게 |
|---|---|
| affect / effect | affect(동사, 영향을 주다) · effect(명사, 효과) |
| data is | **data are** (복수) |
| compare to / with | 차이를 비교할 때는 compared **with** |
| which / that | 꼭 필요한 정보면 that (쉼표 없음), 덧붙이는 정보면 , which |
| i.e. / e.g. | i.e. = 즉 · e.g. = 예를 들어 |
| while / whereas | 대조는 whereas (while은 '동안'과 헷갈림) |
| since / because | 이유는 because (since는 '이후') |
| less / fewer | 셀 수 있으면 fewer cells · 셀 수 없으면 less protein |
| respectively | A and B were 10 and 20, respectively. (순서 대응) |

## 7. 한국어식 실수

- ✗ researches · informations · evidences → research · information · evidence (셀 수 없음)
- ✗ According to the result, … → These results indicate that …
- ✗ very significantly · more significantly → 유의성에는 정도 부사 X, 효과 크기·p로
- ✗ In this study를 문단마다 → 한 번이면 충분
- 관사: 처음 나오면 a/an, 이미 말한 것·하나뿐인 것은 the. 복수 일반론은 관사 없이 (Cells were …)
- 숫자로 문장 시작 X: ✗ 10 mice were … → Ten mice were …
