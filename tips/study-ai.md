# 공부 · AI 활용

> 학교·저널의 AI 사용 규정이 항상 먼저예요.

## 1. 논문 읽기 — 3단계

| 단계 | 시간 | 무엇을 |
|---|---|---|
| 1. 훑기 | 5–10분 | 제목 · 초록 · 그림 · 마지막 문단. 읽을 가치가 있나 |
| 2. 그림 중심 | 30–60분 | 그림 하나씩: 무엇을 물었나 → 어떻게 → 무엇이 나왔나. legend의 n·통계 확인 |
| 3. 깊게 | 1–2시간 | 방법·대조군·통계 비판, 다른 해석 가능성, 우리 실험에 쓸 것 |

**읽으며 적을 질문**: 연구 질문은? · 핵심 그림 하나는? · 대조군은 적절한가? · n과 통계는? · 다른 설명은 없나? · 우리 연구에 무엇을 가져올까?

## 2. 문헌 찾기

- **PubMed**: MeSH 용어, `[tiab]`(제목·초록) 검색, 필터(Review, 최근 5년)
- **Google Scholar**: "Cited by"로 이후 연구 따라가기
- 처음 분야면 최근 **리뷰 논문**부터 → 거기 인용된 핵심 논문으로
- **알림**: PubMed(My NCBI) · Google Scholar alert에 키워드·저자 등록

## 3. 기록·관리

- **Zotero**(무료): 브라우저에서 한 번에 저장, PDF 메모, 그룹 라이브러리로 랩 공유
- 논문 한 편 = 노트 한 장: 질문 / 핵심 결과 3개 / 방법 메모 / 한계 / 우리 연구와 연결
- 실험 기법은 원리부터: qPCR(ΔΔCt), flow cytometry(gating), 통계(검정 고르기) — 랩 프로토콜 탭과 같이 보기

## 4. AI(ChatGPT · Claude · Gemini 등) 쓰는 법

| 잘하는 것 | 조심할 것 |
|---|---|
| 개념을 내 수준에 맞춰 설명 | **참고문헌·수치를 지어낼 수 있음** — 원문·DOI로 꼭 확인 |
| R·Python 코드 작성, 오류 고치기 | 그럴듯하지만 틀린 설명 (특히 최신 내용) |
| 영어 문장 다듬기 (문법·흐름) | 통계 방법 추천을 그대로 믿기 (위 '분석' 표로 확인) |
| 요약 초안, 실험 계획 브레인스토밍 | 계산 결과 — 직접 다시 계산하기 |

### 절대 넣지 않을 것

- 환자 개인정보·의무기록, 사람 시료 정보
- **미발표 데이터·원고**, 심사 중인 남의 원고(리뷰어로 받은 것)
- 과제 제안서·특허 전 아이디어 등 비밀 내용, 계정·비밀번호

### 논문·과제에 쓸 때

- 투고할 저널의 AI 정책 확인: 대부분 AI는 저자가 될 수 없고, 쓴 사실을 Methods나 Acknowledgments에 밝혀요
- AI로 데이터 그림(블롯·현미경 사진 등)을 만들거나 고치면 안 돼요
- 내용·주장·해석의 책임은 저자에게 있어요

## 5. 좋은 질문(프롬프트) 틀

**상황(나는 누구) → 목표 → 자료 붙이기 → 원하는 형식 → 확인 요청**

- 개념: "나는 의생명과학 석사 1년차야. Western blot에서 loading control이 왜 필요한지, 흔한 실수 3가지와 함께 설명해 줘."
- 코드: "R에서 이 데이터(아래 붙임)를 two-way ANOVA로 분석하고 ggplot2로 dot plot을 그리고 싶어. 코드와 각 줄 설명, 가정 확인 방법도 알려 줘."
- 영어: "아래 문단의 문법과 흐름만 고쳐 줘. 내용과 주장은 바꾸지 말고, 바꾼 곳을 표로 보여 줘."
- 논문: "이 초록을 읽고 (1) 연구 질문 (2) 핵심 방법 (3) 주요 결과 (4) 가능한 한계를 한 줄씩. 초록에 없는 내용은 모른다고 해."

## 6. AI 답 확인하는 3가지

1. **원문 확인** — 참고문헌·수치는 PubMed·논문에서 직접
2. **교차 확인** — 교과서·리뷰·선배·교수님께 한 번 더
3. **직접 해 보기** — 코드는 작은 예제로 돌려 보고, 계산은 손으로 다시
