# 발표 · PPT 만들기

> 랩 발표 양식이 있으면 그걸 먼저 따라요.

## 1. 가장 중요한 규칙

- **한 장 = 한 메시지.** 슬라이드 제목에 그 장의 결론을 문장으로 써요. ✗ "Result 2" → ✓ "KO 세포에서 X 발현이 절반으로 줄었어요"
- **1장 ≈ 1분.** 데이터 슬라이드는 1.5–2분. 15분 발표면 12–15장.
- 듣는 사람이 **3초 안에** 어디를 봐야 할지 알게: 강조는 한 곳, 화살표·색 하나.

## 2. 발표 종류별 구성

| 종류 | 시간 | 구성 |
|---|---|---|
| 랩 미팅 (진행 보고) | 15–30분 | 지난번 계획 → 이번에 한 것 → 결과(실패 포함) → 해석 → 다음 계획 → 도움 필요한 것 |
| 저널 클럽 | 20–30분 | 배경·질문 → 핵심 그림 3–4개 → 강점·한계 → 우리 연구와 연결 → 토론 질문 2–3개 |
| 학회 구두 | 10–15분 | 질문(왜 중요한가) → 가설 → 핵심 결과 3개 → 결론 한 장 → 감사 |
| 포스터 | — | 제목에 결론, 그림 위주, 글은 짧게, 1.5 m 거리에서 읽히게 |
| 학위 심사 | 30–45분 | 큰 질문 → 장(chapter)별 질문·결과 → 종합 모델 그림 → 한계·앞으로 |

## 3. 슬라이드 한 장의 틀 (데이터 장)

1. **제목**: 결론 한 문장
2. **무엇을 했나**: 실험 모식도 작게 (세포·처리·시간)
3. **결과**: 그래프 하나를 크게, 비교할 막대·점에 표시
4. **아래 한 줄**: 그래서 무슨 뜻인지 (다음 장으로 이어지는 질문)

## 4. 보기 좋게

| 항목 | 기준 |
|---|---|
| 글씨 | 제목 28–36 pt, 본문 18 pt 이상, 그래프 축 글씨 14 pt 이상 |
| 글 양 | 본문 3–5줄, 문장보다 짧은 구절 |
| 글꼴 | 한 가지 (예: Pretendard·맑은 고딕 + 영문 Arial), 굵기로만 구분 |
| 색 | 기본 2–3색 + 강조 1색. 빨강–초록 같이 쓰지 않기 (색맹) |
| 그림 | 논문 그림을 통째로 붙이지 말고 필요한 패널만 크게 다시 |
| 표 | 꼭 필요한 줄만, 중요한 칸은 굵게·색 |
| 애니메이션 | 순서대로 보여 줄 때만 (나타내기), 날아오기·회전 X |
| 번호 | 슬라이드 번호 넣기 (질문할 때 편함) |

## 5. 발표 전 체크리스트

- [ ] 제목만 넘겨 읽어도 이야기가 이어지나
- [ ] 모든 그래프에 축 이름·단위·n·통계 표시가 있나
- [ ] 약어를 처음 나올 때 풀었나
- [ ] 시간 재며 소리 내어 2번 연습했나
- [ ] 발표 장소 화면 비율(16:9)·글꼴 깨짐 확인 (PDF로도 저장)
- [ ] 예상 질문 5개와 답, 보충 슬라이드(뒤쪽에) 준비

## 6. 자주 하는 실수

- 글을 슬라이드에 다 쓰고 읽기 → 말할 것은 메모(노트)로
- 결과 장이 너무 많음 → 메시지에 필요한 것만, 나머지는 보충 슬라이드
- 레이저로 화면을 계속 휘젓기 → 가리킬 곳만 잠깐
- "보시다시피…" → 무엇을 봐야 하는지 직접 말하기
- 실패한 실험을 숨김 → 랩 미팅에서는 오히려 꼭 보여 주고 도움 받기

## 7. 질문 받을 때

1. 질문을 끝까지 듣고, 한 번 짧게 다시 말해요 ("○○에 대한 질문이시죠")
2. 답 → 근거(데이터·슬라이드 번호) 순서로 짧게
3. 모르면 "확인해 보겠습니다", 좋은 제안이면 "다음 실험에 넣어 보겠습니다"
