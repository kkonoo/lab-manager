# 그림 만들기 (논문·발표 figure)

> 투고할 저널의 그림 규정(크기·해상도·파일 형식)이 항상 먼저예요.

## 1. 원칙

- **그림 하나 = 메시지 하나.** 패널들이 한 이야기를 하게 배치해요.
- 데이터를 가리는 장식(3D, 그림자, 무늬, 배경색)은 빼요.
- 같은 그룹은 논문 전체에서 **같은 색·같은 순서**로.

## 2. 크기 · 글씨 · 해상도

| 항목 | 기준 (저널마다 조금 다름) |
|---|---|
| 그림 폭 | 1단 약 85–89 mm, 1.5단 약 120–140 mm, 2단 약 174–183 mm |
| 처음부터 | **최종 크기로** 만들기 (나중에 줄이면 글씨가 너무 작아짐) |
| 글씨 | 최종 크기에서 6–8 pt, 패널 문자(A, B, C)는 8–10 pt 굵게 |
| 글꼴 | Arial / Helvetica 한 가지 |
| 선 | 0.5–1 pt |
| 해상도 | 사진 300 dpi 이상 · 사진+글자 600 dpi · 선 그림 1000 dpi 이상, 또는 벡터 |
| 파일 | 그래프·모식도는 벡터(PDF, EPS, SVG), 사진은 TIFF (JPEG 압축 X) |
| 색 | 대부분 RGB (인쇄용 CMYK를 요구하는지 규정 확인) |

## 3. 색

- **빨강–초록을 같이 쓰지 않기** (적록 색맹). 형광 merge는 magenta/green이나 cyan/yellow
- 그룹 색은 색맹에 안전한 **Okabe–Ito** 팔레트 추천:

| 색 | HEX |
|---|---|
| 검정 | #000000 |
| 주황 | #E69F00 |
| 하늘 | #56B4E9 |
| 청록 | #009E73 |
| 노랑 | #F0E442 |
| 파랑 | #0072B2 |
| 주홍 | #D55E00 |
| 자주 | #CC79A7 |

- 연속값(heatmap)은 viridis · cividis, 양·음이 있는 값은 파랑–흰–빨강 같은 diverging
- 색맹 시뮬레이터(Coblis 등)로 한 번 확인

## 4. 그래프

- 점은 가능한 한 **모두 보이게** (dot plot, box + 점). 평균 막대만 X — '분석' 팁 참고
- 막대 그래프의 y축은 0부터
- 축 이름 + 단위, 로그 축이면 표시
- 범례보다 선·점 옆에 **바로 이름** 붙이기
- 유의 표시: 정확한 p 또는 *를 legend에 정의 (* p < 0.05 …), 비교한 쌍을 선으로

## 5. 패널 배치

- 왼쪽 위부터 A → B → C (읽는 순서대로)
- 격자에 맞춰 정렬, 패널 사이 간격 일정
- 같은 종류 그래프는 크기·축 범위를 맞춰서 비교하기 쉽게

## 6. 이미지 정직성 (꼭 지키기)

- **원본 파일 보관** (현미경·블롯 원본, 촬영 설정 포함)
- 밝기·대비 조정은 **이미지 전체에 똑같이, 선형으로**. 대조군과 실험군은 같은 설정
- 일부만 지우기·복사하기·붙이기 X
- 블롯을 잘랐으면 **잘리지 않은 원본 전체**를 보충 자료로, 다른 젤·다른 노출을 이어 붙였으면 경계선 표시
- 대표 이미지는 정말 대표하는 것으로 + 정량 그래프 같이
- 저널은 이미지 조작 검출 도구로 확인해요

## 7. 현미경 · 블롯

- 모든 현미경 사진에 **scale bar** (길이는 legend나 그림에)
- 같은 비교 안에서는 같은 노출 시간·게인·표시 범위
- 블롯: 분자량 마커 위치, loading control, 같은 막에서 잰 것인지 표시

## 8. 도구

| 할 일 | 도구 |
|---|---|
| 그래프 + 통계 | GraphPad Prism |
| 재현 가능한 그래프 | R `ggplot2`, Python `matplotlib` · `seaborn` |
| 패널 모으기 · 벡터 편집 | Inkscape(무료), Adobe Illustrator, Affinity Designer |
| 이미지 정량 · scale bar | ImageJ / Fiji |
| 모식도 | BioRender (출판 라이선스·인용 문구 확인), 직접 그리기 |
| 간단한 조립 | PowerPoint (최종 해상도로 내보내기 주의) |
