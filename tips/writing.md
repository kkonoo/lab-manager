# 논문 쓰기

> 투고할 저널의 규정(Guide for Authors)이 항상 먼저예요.

## 1. 쓰는 순서

**그림·표 → Methods → Results → Introduction → Discussion → Abstract → Title**

그림이 정해지면 이야기가 정해져요. 그림을 먼저 순서대로 늘어놓고, 각 그림의 결론을 한 문장씩 써 보면 그게 Results의 뼈대예요.

## 2. 부분별 체크

| 부분 | 무엇을 | 흔한 실수 |
|---|---|---|
| Title | 핵심 결과를 짧게 (가능하면 결론형) | 너무 길거나 "Study of …"처럼 막연함 |
| Abstract | 배경 1–2문장 → 질문 → 방법 → 주요 결과(수치) → 결론·의미 | 결과 수치 없이 "significantly changed"만 |
| Introduction | 넓은 배경 → 아직 모르는 것(gap) → 우리 질문·가설 → 이 연구에서 한 것 한 문단 | 배경만 길고 gap이 흐림 |
| Methods | 남이 따라 할 수 있게 (시약 회사·Cat. No., 세포주 출처, 동물·IRB 번호, 통계) | "as usual", 통계 방법 빠짐 |
| Results | 그림 하나 = 단락 하나: 질문 → 실험 → 결과(수치·통계) → 한 줄 해석 | 해석·문헌 비교를 너무 많이 (Discussion으로) |
| Discussion | 주요 발견 요약 → 기존 연구와 비교 → 의미·기전 → 한계 → 결론·앞으로 | 결과 반복, 한계 숨기기 |
| Figure legend | 제목(결론) → 무엇을 보였나 → n·오차 막대·검정 → scale bar | n과 오차 막대 종류 빠짐 |

## 3. Introduction 깔때기 (4문단 예)

1. 이 분야가 왜 중요한가 (질환·현상, 큰 그림)
2. 지금까지 알려진 것 (핵심 문헌)
3. **그런데 모르는 것** — "However, it remains unclear whether …"
4. 이 연구 — "Here, we show that …" + 주요 결과 한두 줄

## 4. 문단과 문장

- 문단 첫 문장 = 그 문단의 요지 (첫 문장만 이어 읽어도 논리가 보이게)
- 한 문장에 한 생각. 25단어 넘으면 나누기
- 같은 것은 같은 말로 (용어를 바꾸면 다른 것으로 읽힘)
- 약어는 처음 나올 때 풀고, 3번 미만으로 쓰면 약어 만들지 않기
- 수치에는 단위와 n: "increased by 2.1-fold (n = 6, p = 0.003)"

## 5. Methods에 빠뜨리기 쉬운 것

- 세포주: 출처(ATCC 등), 인증(STR), mycoplasma 검사
- 항체: 회사·Cat. No.·희석 배율 (RRID 있으면)
- 동물: 계통·성별·나이, 사육 조건, IACUC 승인 번호 / 사람 시료: IRB 번호, 동의
- 통계: 검정 이름, n의 정의, 오차 막대, 소프트웨어·버전
- 데이터·코드 공개: GEO·SRA 번호, GitHub 등

## 6. 참고문헌

- **Zotero**(무료) 또는 EndNote로 관리, Word 플러그인으로 넣기
- 인용한 내용은 원문에서 직접 확인 (리뷰 논문을 거친 재인용 주의)
- AI가 알려 준 참고문헌은 반드시 PubMed·DOI로 실제 있는지 확인

## 7. 투고 전 체크리스트

- [ ] 저자 순서·기여(CRediT)·교신저자 합의
- [ ] 저널 형식: 단어 수, 그림 수, 참고문헌 스타일, 그림 해상도·파일 형식
- [ ] 윤리: IRB/IACUC, 이해상충, 연구비 표기(과제 번호)
- [ ] 데이터 공개 번호, 보충 자료 정리
- [ ] 그림 원본(블롯 전체 사진 등) 보관
- [ ] Cover letter: 무엇을 발견했고 왜 이 저널 독자에게 중요한지 3–4문단

## 8. 리뷰어 답변 (response letter)

- 지적을 모두 번호 매겨 그대로 옮기고, 아래에 답
- 감사 → 한 일(추가 실험·수정) → 바뀐 위치(페이지·줄 번호)
- 동의하지 않으면 근거(데이터·문헌)로 정중히. 감정적 표현 X
- 원고의 바뀐 부분은 색이나 변경 추적으로 표시
